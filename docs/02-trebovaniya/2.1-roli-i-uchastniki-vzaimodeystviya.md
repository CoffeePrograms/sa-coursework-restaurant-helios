# 2.1. Роли и участники взаимодействия

Роли пользователей приведены в [таблице 2.1](#tablitsa-2-1), права ролей — в [таблице 2.2](#tablitsa-2-2), внешние участники — в [таблице 2.3](#tablitsa-2-3).

Таблица 2.1 — Роли пользователей
{: #tablitsa-2-1 .caption }

| Роль | Кто это | Что делает в системе |
| --- | --- | --- |
| Сотрудник | Работник компании | Бронирует обед: блюда, время и место за столом |
| Менеджер | Работник компании, отвечает за обеды | Ведет блюда, меню и схему зала, формирует отчет для ресторана |
| Администратор | Работник компании, сопровождает систему | Управляет пользователями и ролями, следит за логами и метриками |

Таблица 2.2 — Права ролей
{: #tablitsa-2-2 .caption }

| Функция | Сотрудник | Менеджер | Администратор |
| --- | --- | --- | --- |
| Бронирование обеда | Да | Да | Да |
| Управление меню | Нет | Да | Да |
| Управление схемой зала | Нет | Да | Да |
| Отчеты для ресторана | Нет | Да | Да |
| Управление пользователями и ролями | Нет | Нет | Да |
| Логи, метрики, нагрузочное тестирование | Нет | Нет | Да |

Бронирование для менеджера и администратора — допущение: они тоже сотрудники компании.

Таблица 2.3 — Внешние участники взаимодействия
{: #tablitsa-2-3 .caption }

| Участник | Тип | Что передает или получает |
| --- | --- | --- |
| Ресторан | Организация | Сообщает менеджеру меню и схему зала, получает от менеджера отчет об обедах |
| iiko | Внешняя система (бэклог) | Меню ресторана и список обедов через API |
| Почтовый сервис | Внешняя система (бэклог) | Отправка отчета ресторану по email |
| Яндекс ID | Внешняя система (бэклог) | Вход через аккаунт Яндекса |
