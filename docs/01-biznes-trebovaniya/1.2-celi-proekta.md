# 1.2. Цели проекта

- перенести заказ обедов из бумажного меню в веб-приложение;
- дать сотруднику выбрать блюда, время и место за столом с компьютера или телефона;
- дать менеджеру отчет об обедах за день для передачи ресторану;
- дать каждому пользователю доступ только к его функциям и защитить данные сотрудников;
- находить сбои и ошибки по логам и метрикам.
