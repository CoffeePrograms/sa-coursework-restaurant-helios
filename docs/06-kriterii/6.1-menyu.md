# 6.1. Меню

## US-01. Управление меню на день {#us-01}

**Как менеджер, я хочу вести список блюд и составлять из него меню на день, чтобы сотрудники выбирали обед из актуального меню.**

Связь: [БП-01](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-01) «Управление меню».

Сервисы: BFF, Menu.

Статус: спринты 1 и 2, частично: блюда, меню и расписание ведутся, проверки обязательных полей блюда ([AC-4](#us-01-ac-4)), [ОГР-03](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-03) ([AC-5](#us-01-ac-5)) и [ОГР-09](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-09) ([AC-7](#us-01-ac-7)) в коде нет, см. [раздел 7.2](../07-rezultat/7.2-naydeno-pri-revizii.md).

Критерии приемки приведены в [таблице 6.1](#tablitsa-6-1).

Таблица 6.1 — Критерии приемки [US-01](#us-01)
{: #tablitsa-6-1 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-01-ac-1"></span>AC-1. Добавление блюда | Допустим менеджер открыл список всех блюд<br>Когда он добавляет блюдо с названием, описанием и типом (суп, горячее, салат или напиток)<br>Тогда блюдо появляется в списке всех блюд |
| <span id="us-01-ac-2"></span>AC-2. Изменение и удаление блюда | Допустим блюдо есть в списке всех блюд<br>Когда менеджер меняет название, описание или тип блюда либо удаляет его<br>Тогда список всех блюд показывает изменения |
| <span id="us-01-ac-3"></span>AC-3. Меню на дату | Допустим в списке всех блюд есть блюда<br>Когда менеджер выбирает блюда и указывает дату меню<br>Тогда меню сохраняется<br>И в указанную дату сотрудники видят его с блюдами, сгруппированными по типам |
| <span id="us-01-ac-4"></span>AC-4. Блюдо без названия или типа (негатив) | Допустим менеджер открыл форму нового блюда<br>Когда он сохраняет блюдо без названия или без типа<br>Тогда система не сохраняет блюдо и показывает, какое поле нужно заполнить<br>[Допущение: обязательные поля блюда — название и тип] |
| <span id="us-01-ac-5"></span>AC-5. Изменение меню после броней (негатив) | Допустим по меню на сегодня уже оформлен хотя бы один обед<br>Когда менеджер пытается изменить это меню<br>Тогда система не сохраняет изменения и сообщает, что по меню есть брони<br>Основание: [ОГР-03](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-03) «Меню с бронями не меняется» |
| <span id="us-01-ac-6"></span>AC-6. Нет прав менеджера | Допустим пользователь вошел без роли менеджера или администратора<br>Когда он открывает систему<br>Тогда функции управления меню ему недоступны |
| <span id="us-01-ac-7"></span>AC-7. Удаление блюда с бронями (негатив) | Допустим блюдо входит в обед на сегодня<br>Когда менеджер удаляет это блюдо<br>Тогда система не удаляет блюдо и сообщает, что по нему есть брони<br>Основание: [ОГР-09](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-09) «Удаление данных с бронями» |
