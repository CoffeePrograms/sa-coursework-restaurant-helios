# 6. Критерии приемки

Для каждой истории ниже приведены формулировка, связи, статус и таблица критериев приемки. Сценарии записаны на Gherkin: Допустим → Когда → Тогда. Если критерий следует из ограничения [раздела 2.2](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md) или нефункционального требования [раздела 2.3](../02-trebovaniya/2.3-nefunkcionalnye-trebovaniya.md), в конце сценария указано основание. Негативные сценарии, в которых система выдает ошибку и прерывает процесс, помечены «(негатив)». Допущения приведены в квадратных скобках, открытые вопросы начинаются со слов «Открытый вопрос». Истории бэклога приведены кратко в [разделе 6.7](6.7-istorii-bekloga.md).
