# 6.3. Отчеты для ресторана

## US-06. Отчет об обедах в PDF {#us-06}

**Как менеджер, я хочу сформировать отчет об обедах за день в PDF, чтобы передать ресторану список заказов в неизменном виде.**

Связь: [БП-04](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-04) «Передача заказов ресторану».

Сервисы: BFF, Lunch.

Пример строк отчета приведен в [таблице 6.6](#tablitsa-6-6).

Статус: спринты 2 и 5, реализовано.

Критерии приемки приведены в [таблице 6.5](#tablitsa-6-5).

Таблица 6.5 — Критерии приемки [US-06](#us-06)
{: #tablitsa-6-5 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-06-ac-1"></span>AC-1. Формирование отчета | Допустим на выбранный день есть обеды<br>Когда менеджер выбирает день и формирует отчет<br>Тогда система создает PDF<br>И для каждого обеда в отчете указаны ФИО сотрудника, стол, место, суп, горячее, салаты и напитки<br>Основание: [ОГР-08](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-08) «Сотрудник в брони» |
| <span id="us-06-ac-2"></span>AC-2. Разделы по времени обеда | Допустим на выбранный день есть брони только на 12:00<br>Когда менеджер формирует отчет<br>Тогда обеды в отчете сгруппированы по времени<br>И раздела «13:00» в отчете нет |
| <span id="us-06-ac-3"></span>AC-3. Обедов нет (негатив) | Допустим на выбранный день обедов нет<br>Когда менеджер формирует отчет<br>Тогда система сообщает, что бронирований на эту дату нет, и не создает файл |
| <span id="us-06-ac-4"></span>AC-4. Нет прав на отчет | Допустим пользователь вошел без роли менеджера или администратора<br>Когда он открывает систему<br>Тогда функция формирования отчета ему недоступна<br>Основание: [НФТ-15](../02-trebovaniya/2.3-nefunkcionalnye-trebovaniya.md#nft-15) «Персональные данные» |

Таблица 6.6 — Пример строк отчета об обедах
{: #tablitsa-6-6 .caption }

| Сотрудник | Стол | Место | Суп | Горячее | Салаты | Напитки |
| --- | --- | --- | --- | --- | --- | --- |
| Сотрудник А | 2 | 1 | Борщ | Галушки | — | Морс |
| Сотрудник Б | 4 | 3 | Уха | Паста болоньезе | Салат оливье | Яблочный сок |

## US-07. Экспорт отчета в Excel {#us-07}

**Как менеджер, я хочу выгружать отчет об обедах в Excel, чтобы при необходимости обрабатывать данные в таблице.**

Связь: [БП-04](../01-biznes-trebovaniya/1.5-biznes-processy.md#bp-04) «Передача заказов ресторану».

Сервисы: BFF, Lunch.

Статус: спринт 2, реализовано.

Критерии приемки приведены в [таблице 6.7](#tablitsa-6-7).

Таблица 6.7 — Критерии приемки [US-07](#us-07)
{: #tablitsa-6-7 .caption }

| Критерий | Сценарий |
| --- | --- |
| <span id="us-07-ac-1"></span>AC-1. Выгрузка в Excel | Допустим на выбранный день есть обеды<br>Когда менеджер выбирает формат Excel и формирует отчет<br>Тогда он получает файл с теми же колонками, что и отчет в PDF ([US-06](#us-06) «Отчет об обедах в PDF») |
| <span id="us-07-ac-2"></span>AC-2. Обедов нет (негатив) | Допустим на выбранный день обедов нет<br>Когда менеджер выгружает отчет в Excel<br>Тогда система сообщает, что бронирований на эту дату нет, и не создает файл |
