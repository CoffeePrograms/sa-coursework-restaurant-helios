# 5.1. Ресурсы и эндпоинты

Эндпоинты BFF приведены в [таблице 5.1](#tablitsa-5-1). Источник — контроллеры TavernHelios.Server в репозитории проекта, маршрут api/[controller], поэтому пути совпадают с именами контроллеров. Базовый путь /api, формат JSON. Эндпоинты сервиса погоды из учебного шаблона в таблицу не включены.

Регистр в пути не важен: маршрутизация ASP.NET Core его не различает, веб-приложение вызывает пути в нижнем регистре (/api/dish, /api/reservation). Методы DELETE для блюда, меню, расписания, схемы зала и обеда принимают ID в теле запроса строкой JSON, DELETE /api/MenuEdit — ID меню и блюда. Перечисления передаются числами ([раздел 3.5](../03-informacionnaya-model/3.5-perechisleniya-i-statusnye-modeli.md)).
