# 5.2. Контракт создания брони

POST /api/Reservation создает обед сотрудника. Поля запроса приведены в [таблице 5.2](#tablitsa-5-2), ответы — в [таблице 5.3](#tablitsa-5-3).

Таблица 5.2 — Поля запроса POST /api/Reservation
{: #tablitsa-5-2 .caption }

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| personId | string | да | ФИО сотрудника из учетной записи ([ОГР-08](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-08)) |
| date | string (дата и время ISO 8601) | да | Дата обеда и время 12:00 или 13:00 ([ОГР-02](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-02)) |
| dishIds | string[] | да | ID блюд из меню на сегодня, от одного до четырех, не больше одного каждого типа ([ОГР-07](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-07)) |
| layoutId | string | да | ID схемы зала |
| tableName | string | да | Название стола на схеме зала |
| seatNumber | int | да | Номер места за столом ([ОГР-04](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-04)) |

Пример запроса:

```json
{
  "personId": "Фамилия Имя Отчество",
  "date": "2025-06-02T12:00:00",
  "dishIds": ["665a1c...01", "665a1c...07"],
  "layoutId": "665a20...0c",
  "tableName": "Стол 2",
  "seatNumber": 1
}
```

Таблица 5.3 — Ответы POST /api/Reservation
{: #tablitsa-5-3 .caption }

| Код | Когда | Тело ответа |
| --- | --- | --- |
| 201 Created | Обед сохранен. После ответа BFF отправляет всем клиентам событие ReservationCreated (/hubs/reservations) | Созданный обед: поля запроса, id и isDeleted = false |
| 400 Bad Request | Сервис Lunch вернул ошибку | Список сообщений об ошибке |
| 401 Unauthorized (целевой) | Запрос без входа ([НФТ-04](../02-trebovaniya/2.3-nefunkcionalnye-trebovaniya.md#nft-04)) | Нет |
| 409 Conflict (целевой) | Место на это время занято ([ОГР-04](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-04)), у сотрудника уже есть обед на сегодня ([ОГР-06](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-06)) или нарушен состав обеда ([ОГР-07](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-07)) | Сообщение с причиной |

Пример ответа 201:

```json
{
  "id": "128",
  "personId": "Фамилия Имя Отчество",
  "date": "2025-06-02T12:00:00",
  "dishIds": ["665a1c...01", "665a1c...07"],
  "seatNumber": 1,
  "tableName": "Стол 2",
  "isDeleted": false,
  "layoutId": "665a20...0c"
}
```

Ответы 401 и 409 — целевые: сейчас метод доступен без входа, а проверки занятости места, одного обеда в день и состава обеда выполняет только интерфейс. Заголовок Location ответа 201 указывает несуществующий путь api/v1/Reservations. Расхождения приведены в [разделе 7.2](../07-rezultat/7.2-naydeno-pri-revizii.md).
