# 3.3. Описание сущностей

Сущности приведены в [таблице 3.1](#tablitsa-3-1). Атрибуты обязательны, если не указано иное.

Таблица 3.1 — Сущности
{: #tablitsa-3-1 .caption }

| Сущность | Сервис | Назначение | Атрибуты |
| --- | --- | --- | --- |
| Пользователь | Authorization | Учетная запись для входа | ID, ФИО (до 100 символов), логин (до 50 символов), хэш пароля |
| Роль | Authorization | Набор прав пользователя | ID, название (до 50 символов) |
| Роль пользователя | Authorization | Связь пользователя и роли | пользователь, роль |
| Блюдо | Menu | Позиция списка всех блюд | ID, название, описание, тип блюда, изображение, признак удаления |
| Меню | Menu | Набор блюд | ID, название, список блюд, признак удаления |
| Расписание меню | Menu | Меню на конкретную дату | ID, меню, дата и время, признак удаления |
| Обед | Lunch | Бронь сотрудника | ID, дата и время обеда, сотрудник (ФИО, [ОГР-08](../02-trebovaniya/2.2-ogranicheniya-i-pravila.md#ogr-08)), схема зала, стол (название), номер места, признак удаления |
| Блюдо обеда | Lunch | Блюдо в составе обеда | ID, обед, блюдо |
| Схема зала | Hall | План зала ресторана | ID, ширина, высота, ресторан (необяз.), подложка (необяз.), столы, признак удаления |
| Стол | Hall | Стол на схеме зала | ID (целевой), название, описание, координаты углов, места |
| Место | Hall | Место за столом | ID (целевой), номер, описание, центр, радиус |

Пометка «(целевой)» означает, что атрибута в коде нет и его нужно добавить: сейчас стол определяется названием в пределах схемы, место — номером в пределах стола.
